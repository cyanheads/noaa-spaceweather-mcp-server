# 0.5.0 — 2026-11-21

## Changed

- **Development and packaging tooling**: sync framework skills and scripts, exclude the Vitest cache from MCPB bundles, and document the JWT audience and issuer settings.

## Fixed

- **Unissued NOAA scale levels** ([#47](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/47)). Breaking output change: clients must accept null for `scale`, `text`, and `label` in `today.G`, `today.R`, `today.S`, and `forecast[].G` when SWPC issues no level. Known values and Kp remain available.
- **Observed periods** ([#49](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/49)). The existing `today` and `yesterday` keys represent latest observations and rolling 24-hour observed maxima. `yesterday.date` carries SWPC’s reported date stamp.
- **Continued alerts** ([#50](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/50)). Active results exclude predecessors uniquely identified by a newer continuation and count them under `exclusions.continued`. History keeps all records in the requested window.
