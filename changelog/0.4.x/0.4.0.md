# 0.4.0 — 2026-10-28

mcp-ts-core 0.13.17 fixes an HTTP transport leak that retained about 71 KiB per request on 0.13.16; this server's Docker image runs under Bun, where sustained traffic grew memory until restart. 0.13.18 adds serving a root `skills/` tree over MCP and trims build-only files from `.mcpb` bundles.

## Added

- **`noaa-spaceweather-guide` skill**, served as the MCP resource `skill://noaa-spaceweather-guide/SKILL.md` (Skills extension, `skill://{+path}` template): judgment for turning Kp, storm scales, solar wind, flares, and alerts into answers about aurora visibility, coming storms, radio blackouts, and impacts on HF radio, GPS, satellites, and power grids. The server `instructions` now point to it.

## Changed

- **`noaa_spaceweather_get_alerts`**: the description and `max_age_hours` now say the SWPC feed holds roughly the last 30 days of products (they claimed it keeps all records).
- **`noaa_spaceweather_get_aurora_forecast`**: the description gives SWPC's stated 30–90 min forecast lead (was ~30–60 min).
- **README install section**: hosted and local one-liners plus a stdio config for other clients; Docker and source-build details moved under Running the server.
- **Packaging**: root Agent Plugins `plugin.json` and `mcp.json`, a root-anchored `.mcpbignore`, and `skills/` in the Docker image and npm package. The `.mcpb` cleaner strips agent-doc trees only at package roots, so the MCP SDK's runtime `dist/ext/skills/` modules stay in the bundle.
- **Development tooling**: framework skills (new `add-skill`) and scripts resynced, and `bunfig.toml` `minimumReleaseAge` 3 days → 1 day.
