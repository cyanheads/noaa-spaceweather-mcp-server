# 0.1.3 — 2026-06-06

## Fixed

- **`get_alerts` `active_only`** now filters by a recency window (`max_age_hours`, default 48 h) before applying the product-type filter, returning only currently-in-force alerts instead of weeks of history (#1).
- **`get_conditions` quiet summary** now walks the 3-day forecast to find peak storm activity when current conditions are quiet, surfacing e.g. `"Quiet now — G3 strong geomagnetic storm forecast for 2026-06-08."` instead of the generic quiet message (#2).
- **`get_aurora_forecast` high-latitude verdict** no longer emits a nonsensical `"Kp≥0 needed"` clause for locations with `minKpRequired === 0` (geomagnetic lat ≥ 65°); verdict language now reflects whether aurora is likely or quiet at the favorable latitude (#3).
- **`get_solar_activity` X-ray flux** formatted via `formatFlux()` — returns `"1.5e-6 W/m²"` (scientific notation + unit) instead of a raw float (#4).
- **`get_conditions` forecast `None`/`none`/empty normalization** — a `scaleText()` helper in `format()` maps all variants to `"—"`, eliminating the mixed-case inconsistency in 3-day forecast rows (#5).
