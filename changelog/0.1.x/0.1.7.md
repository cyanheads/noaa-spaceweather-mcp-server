# 0.1.7 — 2026-06-22

## Changed

- **`get_alerts` validity window** — `validFrom`/`validTo` now parse the full SWPC label set (`Valid From`/`Valid To`, `Now Valid Until`, `Begin Time`/`End Time`) and normalize to ISO 8601 UTC, consistent with `issueDatetime`. Previously `validTo` was `null` on every product and the values were left in raw SWPC format (`2026 Jun 13 0126 UTC`). Products with no time line keep `null` ([#10](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/10)).
- **`kpToGScale`** exported from `space-weather-service.ts` and imported by `get-kp-index.tool.ts`, removing the byte-identical duplicate. Internal; no behavior change ([#11](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/11)).

## Fixed

- **`get_solar_activity` `latestProton.fluxPfu`** rounded to 3 significant figures instead of returning the raw IEEE-754 float (e.g. `0.2243340015411377` → `0.224`). Stays a `number`; the S-scale is still classified from the raw value ([#8](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/8)).
