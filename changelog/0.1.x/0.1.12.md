# 0.1.12 — 2026-08-25

## Changed

- **MCP SDK v2 support** — adopts `@cyanheads/mcp-ts-core` 0.12.3 and the MCP SDK v2 server stack. Streamable HTTP clients can negotiate the modern `2026-07-28` protocol or a 2025-era protocol without changing the server's six-tool surface.
- **Strict tool inputs** — undeclared fields are now rejected before handler execution and returned as normal MCP tool errors that name the unknown field, instead of being silently stripped.
- **Explicit stateless HTTP sessions** — `.env.example`, the Docker image, and the README now consistently select stateless mode. STDIO behavior is unchanged.
- **Current framework scaffold** — refreshes the Bun 1.4 container and package-manager baseline, TypeScript 7 build configuration, MCPB cleanup, release checks, agent skills, and community health files.

## Fixed

- **Security contact** — vulnerability reports now route to `security@caseyjhand.com`.
