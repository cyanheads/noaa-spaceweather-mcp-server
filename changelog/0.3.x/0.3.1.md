# 0.3.1 — 2026-09-22

## Changed

- **Output-schema descriptions** across all six tools now state value, unit, and null case only — design rationale moved to `docs/design.md` and code comments. Summed output-field description bytes drop from 23,849 B to 12,525 B, against a 14,300 B budget `tests/tools/output-schemas.test.ts` now guards; `tools/list` (stdio, 6 tools) drops from 59,209 B to 47,806 B ([#40](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/40))
- **`get_solar_activity`** no longer renders the per-day `(legacy: …)` line in `format()`; a deprecated `*1Day` value now renders in `content[]` only when it disagrees with its date-neutral alias

## Deprecated

- **`cClass1Day`/`mClass1Day`/`xClass1Day`/`protons1Day`** (`get_solar_activity`) — descriptions now read deprecated and name the date-neutral alias (`cClassProbability`, `mClassProbability`, `xClassProbability`, `protonEventProbability`). Values and `outputSchema` shape are unchanged; callers still reading the `*1Day` names should move to the aliases before the fields are removed in a future breaking release ([#16](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/16))
