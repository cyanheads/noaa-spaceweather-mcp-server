# 0.2.0 — 2026-09-17

## Added

- **`get_solar_wind`:** `resolution` input (`reduced`/`full`, default `reduced`) bounds `plasma`/`mag` to 200 records each — one real measurement per bucket (fastest speed for plasma, most southward Bz for mag), newest record always last. A default 3-hour call is unaffected; a 24-hour call drops from ~541 KB to ~75 KB. Adds `bzMinInWindow` + `bzMinTimeTag`, computed from the full window before reduction. [#24](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/24)
- **`get_solar_activity`:** `recentFlares[]` — discrete GOES flare events from `xray-flares-7-day.json`, filtered by the new `flare_hours` input (1–168, default 24), with peak class, R-scale level, and begin/max/end times and classes. [#31](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/31)
- **`get_solar_activity`:** `f107` — the latest daily F10.7 cm solar radio flux (the Noon Penticton report, matching SWPC's own daily summary), with its 90-day mean when available. [#31](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/31)
- **`get_solar_activity`:** `XraySchema` gains `flareClassFull` (class with magnitude, e.g. `"M5.2"`, truncated to one decimal, as SWPC writes its published classes) and `fluxWm2Value` (unformatted flux, for comparison without parsing `fluxWm2`). [#31](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/31)
- **`get_conditions`:** `include_discussion` input + `discussion` output — SWPC's forecaster-written Forecast Discussion, parsed into per-topic sections (summary/forecast text). [#32](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/32)

## Changed

- **Breaking:** `get_conditions.forecast[].R`/`.S` no longer coerce SWPC's null forecast scale to `0`. Forecast days now carry a nullable `scale`/`text`/`label` plus probability fields — `minorProbPercent`/`majorProbPercent` for R, `probPercent` for S — since SWPC issues a probability, not a level, for future days. `today` and `forecast[].G` are unaffected. [#23](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/23)
- **Breaking:** `get_conditions.observedAt` is now ISO 8601 UTC (`"2026-09-17T17:15:00Z"`) instead of the space-separated `"2026-09-17 17:15:00"`. [#23](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/23)
- `get_solar_activity`'s X-ray flux feed swapped from `xrays-7-day.json` to `xrays-6-hour.json` — byte-identical records for the tool's past-hour slice, ~4.52 MB → ~162 KB per call. [#31](https://github.com/cyanheads/noaa-spaceweather-mcp-server/issues/31)
